RANGKUMAN IMPLEMENTASI BACKEND PHP PROSEDURAL
===============================================

Project : grooming-dr-meow
Branch  : feat/backend-implementation (backup: backup/feat-backend-implementation-express)
Tanggal : 21 Oktober 2026
Tujuan  : Migrasi backend dari Express (Node.js) ke PHP Prosedural sesuai materi week5.pptx & php_learning_roadmap.md

1. LATAR BELAKANG
-----------------
Berdasarkan materi Pertemuan 5 "From Client-Side to Server-Side" dan php_learning_roadmap.md,
dilakukan migrasi backend ke PHP murni prosedural dengan menerapkan konsep:
- Server Setup (php -S)
- Variables
- Conditional (if/else)
- Loop (foreach/for)
- Function (dengan argumen & return value)
- Output (JSON)

Pendekatan yang digunakan: Karpathy Guidelines (simpel, surgical change, jelas tujuan),
Clean Code, dan modularisasi prosedural sederhana menggunakan include/require.

2. MAPPING PPT/ROADMAP -> IMPLEMENTASI PHP
------------------------------------------
| Konsep | Implementasi | Keterangan |
|---|---|---|
| Server Setup | php -S localhost:8000 -t backend | Menjalankan local server PHP (built-in server) |
| Variables | $variable, define() di config | Digunakan untuk path, konstanta, data |
| Conditional (if/else/switch) | validasi di includes/functions.php & api/bookings.php | Validasi field wajib, validasi pickupAddress untuk Antar-Jemput |
| Loop (foreach) | foreach untuk validasi required fields & iterasi data | Diterapkan secara eksplisit |
| Function | includes/functions.php, includes/helpers.php | Fungsi prosedural dengan argumen & return value (validateBookingInput, createBookingId, processBooking, appendBooking) |
| Output | sendJson() dengan header application/json | Menghasilkan output JSON untuk konsumsi frontend React |

5. ENDPOINT YANG TERSEDIA
-------------------------
| Method | Endpoint | Fungsi | Status |
|---|---|---|---|
| GET | /api/health | Cek status server | 200 {success:true, data:"ok"} |
| GET | /api/services | Ambil daftar layanan dari data/services.json | 200 {success:true, data:[...]} |
| GET | /api/bookings | Ambil daftar booking dari data/bookings.json | 200 {success:true, data:[...]} |
| POST | /api/bookings | Tambah booking baru (validasi seperti versi Express) | 201 {success:true, data:{...}} / 400 jika error validasi |

Validasi POST (persis seperti server.js):
- Field wajib: customerName, customerPhone, service, bookingDate, bookingTime, catName, arrivalMethod
- Jika arrivalMethod = "Antar-Jemput", pickupAddress wajib diisi
- ID booking: BK- + base36 timestamp + 4 hex random
- createdAt: format ISO (date('c'))
- Data disimpan ke data/bookings.json (append)

6. CARA MENJALANKAN
-------------------
Langkah 1: Jalankan backend PHP
$ cd "/data/WEB grooming"
$ npm run start:php
atau langsung:
$ php -S localhost:8000 -t backend

Server berjalan di: http://localhost:8000

Langkah 2: Jalankan frontend (di terminal terpisah)
$ cd "/data/WEB grooming/frontend"
$ npm run dev

Frontend berjalan di: http://localhost:5173
Proxy /api akan mengarah ke http://localhost:8000

Verifikasi cepat:
$ curl http://localhost:8000/api/health
$ curl http://localhost:8000/api/services
